# Orbital Miner - Game Design Document

## 1. Concept & Hook (web-first, instant engagement)

**Core Concept**: A space mining action-puzzle game where players pilot a mining drone through asteroid fields, collecting resources while avoiding hazards and managing fuel/oxygen.

**Hook**: "Mine asteroids, upgrade your ship, survive the void"
- Immediate visual feedback with particle effects and screen shake
- Risk/reward mechanics: deeper into asteroid fields = better resources but more danger
- Progressive ship upgrades provide tangible power growth
- Procedurally generated asteroid fields ensure endless replayability

**Target Audience**: Casual to mid-core players seeking quick, satisfying sessions with progression

**Unique Selling Points**:
- Dynamic asteroid physics with realistic momentum
- Resource management creates tactical decision-making
- Modular ship upgrade system with visible changes
- Atmospheric space ambiance with minimalist UI

## 2. Core Loop (sessions 2-10 min, replayable)

**Primary Loop** (30-90 seconds):
1. **Launch** → Select upgrade loadout and launch into asteroid field
2. **Mine** → Navigate asteroids, collect resources, avoid hazards
3. **Survive** → Manage fuel/oxygen while maximizing collection
4. **Return** → Choose when to return to base before resources are lost

**Secondary Loop** (2-5 minutes):
1. **Upgrade** → Spend resources on ship improvements
2. **Plan** → Choose next mining zone difficulty/reward tier
3. **Repeat** → Launch with improved capabilities

**Session Goals**:
- Collect enough resources for next upgrade
- Survive progressively dangerous asteroid fields  
- Achieve daily mining quotas for bonus rewards
- Unlock new ship modules and mining zones

**Retention Hooks**:
- "Just one more upgrade" progression
- Daily challenges with unique rewards
- Leaderboards for longest survival/most resources
- Achievement system for mining milestones

## 3. Mechanics (keyboard+mouse+touch controls)

**Core Mechanics**:
- **Thrust-based Movement**: Realistic space physics with momentum
- **Resource Collection**: Laser mining beam with limited energy
- **Hazard Avoidance**: Asteroid collisions, space storms, fuel depletion
- **Risk Management**: Deeper zones = better rewards but higher danger

**Control Scheme**:

**Keyboard + Mouse**:
- WASD / Arrow Keys: Thrust in 4 directions
- Mouse: Aim mining laser
- Left Click: Fire mining laser (hold to continuous beam)
- Right Click: Emergency brake thrusters
- Spacebar: Return to base (when available)

**Touch Controls**:
- Left Virtual Joystick: Movement thrust
- Right Side Tap/Hold: Mining laser (auto-aims to nearest asteroid)
- Two-finger Tap: Emergency brake
- Return Button: Visible return to base option

**Advanced Mechanics**:
- **Momentum Conservation**: Ship drifts realistically in space
- **Energy Management**: Mining laser and thrusters share power core
- **Asteroid Physics**: Large asteroids break into smaller pieces when mined
- **Environmental Hazards**: Solar flares, electromagnetic storms, gravity wells

## 4. Levels & Progression (clear goals per session)

**Zone Structure**:
1. **Inner Belt** (Tutorial): Safe, low-reward asteroids
2. **Mid Belt** (Beginner): Moderate hazards, standard resources
3. **Outer Belt** (Intermediate): Dense fields, rare metals, fuel concerns
4. **Deep Space** (Advanced): Extreme hazards, premium resources
5. **Anomaly Zones** (Expert): Unique environmental challenges, legendary materials

**Progression Systems**:

**Ship Upgrades**:
- **Hull Reinforcement**: Survive more collisions
- **Efficient Engines**: Reduced fuel consumption
- **Mining Laser MK2/3**: Faster resource extraction
- **Cargo Expansion**: Carry more resources per trip
- **Life Support**: Extended oxygen for longer expeditions

**Resource Types**:
- **Iron** (Common): Basic upgrade currency
- **Titanium** (Uncommon): Mid-tier improvements  
- **Rare Earth** (Rare): Advanced ship modules
- **Quantum Crystals** (Legendary): Ultimate upgrades
